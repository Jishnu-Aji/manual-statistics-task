# Manual Statistics Task

## Objective
To manually calculate statistical measures using a dataset.

## Dataset
78, 85, 92, 88, 95, 73, 81, 90, 87, 93, 76, 89

## Results
- Mean = 85.58
- Median = 87.5
- Variance = 46.08
- Standard Deviation = 6.79
- Probability of score greater than 90 = 25%

## What I Learned
- How to calculate mean manually
- How to find median
- How variance and standard deviation work
- Basics of probability calculation
